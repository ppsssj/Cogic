# 검토자 선언서

## 약속

- 검토가 끝나 제출하기 전까지 위 자료(도구 출력, 기존 정답, 점수)를 찾아보지 않는다.
- 다른 검토자와 사례 내용을 논의하지 않는다. 질문은 연구자에게만 하고 `questions.csv`에 남긴다.
- 생성형 AI를 쓰면 사례마다 `time-log.csv`의 `note`에 도구와 용도를 적는다. 관계 판정 자체를 AI에 맡기지 않는다.
