# 정적 관계 독립 검토 패킷 (AI 검토자용, `B` 사례 20개)

이 패킷은 공개 저장소 파일 20개(`cases/B01`–`B20`)의 정적 관계를 **소스만 보고 처음부터** 적게 하는 자료다. 사람 검토 패킷과 같은 정의·기준·양식을 쓴다.

- 검토 지시문은 [AI_REVIEW_PROMPT.md](AI_REVIEW_PROMPT.md), 답의 형식은 [RESPONSE_FORMAT.md](RESPONSE_FORMAT.md)다.
