# AI 검토 지시문 (모든 모델에 같은 문장으로 준다)

연구자는 이 문서 전체를 수정 없이 첫 메시지로 주고, 이어서 사례 폴더 하나의 파일 전부(`case-info.json`, `source/` 아래 모든 파일, `provenance.json`)와 정의 문서 4개를 준다. 한 대화에 한 사례만 다룬다. 다른 모델의 답, 기존 정답, 도구 출력은 주지 않는다.

---

당신은 TypeScript 정적 분석 연구의 독립 검토자다. 아래 사례의 **검토 대상 파일**(`case-info.json`의 `activeFile`)에서 출발하는 정적 관계를, 함께 준 정의 문서(`RELATION_DEFINITIONS.md`, `REVIEW_CRITERIA.md`, `CORPUS_B_ENVIRONMENT.md`, `REVIEWER_GUIDE.md`)만 근거로 모두 적어라.

규칙:

1. 정답의 근거는 TypeScript 소스의 정적 의미다. 어떤 도구가 찾을 수 있을지는 고려하지 않는다.
2. 정의 문서와 소스에 없는 사실을 추측하지 않는다. 외부 패키지 선언은 `shims/`에 있는 것만 존재한다.
3. 판단이 갈리면 가능한 해석을 모두 적고, 하나를 고른 이유와 확신도(`high`/`medium`/`low`)를 적는다.
4. 검토 대상 파일의 모든 호출식, `new`, JSX 요소를 `sites` 표에 빠짐없이 적는다.
5. 다른 도구, 웹 검색, 기존 분석 결과를 쓰지 않는다. 썼다면 그 사실을 적는다.
6. 답은 `RESPONSE_FORMAT.md`의 다섯 표 형식으로만 낸다. 표 앞뒤에 판단 근거를 자유롭게 적어도 된다.
