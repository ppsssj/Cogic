# 09. 측정 한계와 미완료 검증 항목

## 측정 한계
1. **단일 PC·저사양 GPU**: 모든 값은 i5-9400F / 8 GB / GT 710 한 대에서 측정했다. 특히 그래프 조작의 끊김은 GPU 프로세스 포화와 시점이 일치했으므로, 다른 GPU에서는 절대값과 병목 양상이 다를 수 있다.
2. **반복 수**: 조건당 독립 실행 3회(진단 2회)다. 사전 판정 규칙으로 방향만 판단했고 통계적 유의성은 검정하지 않았다. P95는 표본이 적어 사실상 상위 값에 가깝다.
3. **시간 기준**: UI 응답 시간은 프레임 콜백 기준이다. Chromium presentation feedback은 일부 추적 표본에서만 측정했고, 물리적 화면 표시는 측정하지 않았다. 확장 호스트의 분석 시작 시각(T1)도 측정하지 않았다.
4. **합성 워크스페이스**: 파일이 작고 구조가 균일하다. 실제 프로젝트에서는 그래프 형태, 캐시 메모리 사용량(항목당 AST 크기), 분석 시간이 다를 수 있다.
5. **자동화 입력**: Playwright의 입력 경로·속도는 사람과 다르다. 조작 측정 구간에 Playwright의 클릭 처리 시간이 섞일 수 있다(노드 선택의 작은 규모 긴 프레임은 원인을 확인하지 못함).
6. **메모리 측정**: 캐시 유지 힙은 강제 GC 전후 차이로 추정했으며, 일부 블록에서 이상값이 있었다.
7. **세션 상태**: 초기 단계(P5, P6 예비)는 Windows 잠금 상태에서 측정했다. 이후 단계는 잠금 해제 상태였다.
8. **하네스 자체의 오류 이력**: 가시성 판정(Fit 후 DOM 존재 가정), 좁은 패널의 검색창, 가려진 클릭 대상 등 하네스 문제를 수정하는 과정에서 생긴 무효 실행은 통계에서 뺐다(원본 자료에는 표시와 함께 보존).

## 미완료 검증
| 항목 | 상태 |
|---|---|
| **사용자 연구 / 개발자 사용성 평가** | **수행하지 않음**. 자동화 결과를 사람의 이해도·생산성 향상으로 해석하지 않는다 |
| **Corpus B 정답 데이터의 독립적인 사람 검토** | **수행하지 않음(미완료)**. 정답 기반 정확도 수치는 이 검토 전까지 잠정치다 |
| 도구 간 비교의 재실행 | P4–P10 기간에 재실행하지 않음(이전 결과 인용). Context Graph는 Windows에서 실행 불가 |
| 다른 GPU·고사양 PC에서의 측정 | 미실시 |
| 물리적 화면 표시 지연 | 미측정(외부 장비 필요) |
| 대규모 그래프 가시성 개선 | 원인은 확인했으나 개선안 불채택([07](07-rejected-optimizations.md)) |
| 그룹 펼침·접기 성능 개선 | 원인 일부 확인, 개선안 불채택 |
| Fit 개선 빌드의 Root 스펙 1회 실패 | 원인 미확정(빌드 문제인지 시점 문제인지 구분 못함) |
| 채택 버전의 UI 회귀 반복 | 스펙별 1회(Root는 기준 버전과 함께 확인) |
