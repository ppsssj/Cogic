# 07. 채택하지 않은 최적화와 성능 상충관계

아래 변경은 모두 실험 브랜치에만 있으며 **이 PR의 코드에 포함되지 않는다.**

## 1. Fit 가시성 개선
| 버전 | 내용 | 효과 | 문제 | 판정 |
|---|---|---|---|---|
| `c951ccb` | 그래프가 최소 배율에 들어가지 않을 때만 활성 파일 그룹을 중심으로 이동(애니메이션) | 편집 결과 확인용 이동 3/6회 → 0회. 편집 직후 DOM·뷰포트·hit-test 모두 참 | **반복 Generate 194 → 569 ms(1,000), 229 → 679 ms(2,000)**. 매 Generate마다 활성 그룹으로 애니메이션 이동하는 동안 가상화가 매 프레임 노드를 다시 마운트함(결과→DOM 46 → 313 ms, 80 → 424 ms). UI 회귀 Root 스펙 1/3회 실패(재실행 2회 통과, 원인 미확정) | 불채택 |
| `e7abe4e` (Fit v2) | 이미 중심이면 유지, 아니면 애니메이션 없이 즉시 이동 | 이동 0회 유지 | 반복 Generate 241 → 386 ms(2,000, +60%), 첫 Generate 2,138 → 2,404 ms(1,000, +12.5%) | 불채택 |

배율 0.1에서는 활성 그룹이 화면 안에 있어도 글자를 읽을 수 없다. 앞으로는 Generate마다 뷰를 옮기지 않고 사용자가 요청할 때만 이동하는 방식을 검토한다(UX 결정 필요, 미구현).

## 2. 렌더링 변경
P10에서 같은 PC·같은 조작으로 비교했다. 실행 3회씩, Latin-square 또는 교차 순서. S = 캐시 + Fit(`c951ccb`)을 기준으로 한다.

| 버전 | 내용 | 개선된 조작 | 악화된 조작 | 판정 |
|---|---|---|---|---|
| R `56c317e` | 렌더 요소 2,000개 이하이면 가상화 끔(모두 렌더) | 확장 pan ≥50 ms 4.2–5.6% → 0.5–1.0%, 2,000파일 확장 zoom 입력 지연 P95 1,000 → 16 ms, 1,000파일 확장 선택 P95 206 → 63 ms | **2,000파일 확장 그룹 펼침·접기 입력 지연 P95 15.5 → 518 ms**, 프레임 P95 484 → 532 ms. 반복 Generate +9–10%(P9) | 불채택 |
| A `f2a60fc` | R + 안정된 핸들러 + 내용이 같은 노드 객체 재사용 | R과 같은 pan·zoom·선택 이득, 1,000파일 확장 펼침·접기 입력 지연 611 → 114 ms | **2,000파일 확장 펼침·접기 입력 지연 15.5 → 586 ms**, 프레임 P95 484 → 605 ms. 그룹을 펼치면 레이아웃이 바뀌어 대부분 노드 위치가 달라지므로 재사용 효과가 없음 | 불채택 |
| B `f65ea4f` | 사용자가 뷰를 움직이는 동안에만 가상화 끔 | 1,000파일 확장 선택 P95 192 → 67 ms | pan·zoom·펼침·접기 대부분 악화(2,000파일 확장 zoom 입력 지연 1,044 → 2,424 ms, 펼침·접기 21.0 → 4.8 fps). 이동 시작·끝마다 전체를 마운트·언마운트하고, 캔버스를 누르기만 해도 이동 제스처가 시작됨 | 불채택 |

## 3. 채택 판단
P10에서 같은 조건으로 Baseline과 비교했다.

| 버전 | 편집 후 갱신(1,000 / 2,000파일) | 반복 Generate | 편집 확인용 이동 | UI 회귀 |
|---|---|---|---|---|
| **캐시만(`e753f5e`, 채택)** | −52.0% / −56.4% | 차이 불분명 | 3 / 6회(기존과 같음) | 전부 통과 |
| 캐시 + Fit(`c951ccb`) | −52.4% / −54.6% | **+193% / +197%** | 0회 | Root 1/3회 실패 |
| 캐시 + Fit v2(`e7abe4e`) | −54.6% / −57.1% | 차이 불분명 / **+60%** | 0회 | 실행 안 함 |
| R(`56c317e`) | −53.1% / −56.3% | +9% / +10% | 0회 | 통과(펼침·접기 악화) |

**성능 향상이 있어도 다른 조작을 심각하게 악화시키는 변경은 채택하지 않는다**는 기준을 적용해, 기존 응답 시간과 UI 동작을 그대로 유지하면서 편집 갱신만 개선하는 캐시 정책 변경만 채택했다.
