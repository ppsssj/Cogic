## 3. 무결성과 분리

- **최초 판단:** 서버 파일로 한 번만 쓰고 읽기 전용이 된다. 새로고침이나 재요청으로 바꿀 수 없다(API·E2E 테스트로 확인).
- **최초와 최종의 분리:** 최초 판단과 최종 판단은 별도 기록이다. 최종 기록에는 최초 판단의 해시가 들어간다.
- **제출본:**
  - 버전별로 불변 파일로 남는다. 재제출하면 새 버전이 생긴다.
  - SHA-256은 결정적 stored ZIP 기준이다.
  - 실명, 서명, 검토자 표기는 제출본에 넣지 않는다.
- **데이터 분리:**
  - TEST와 REAL은 별도 `DATA_DIR`이고, 서버가 섞어 쓰기를 거부한다.
  - 역할은 `independent`, `researcher-self`, `test`이며 집계도 역할별로 따로 한다. 연구자 본인의 응답을 블라인드 독립 검토로 세지 않는다.
- **REAL 모드 초대 조건:** 독립 검토자 초대는 문제 세트 해시 승인, 학습 자료 해시 승인, 연구 참여 안내문(`consent-notice.md`)이 모두 있어야 가능하다.

| 문제·해석·그래프·출처(S1) | S1-draft | `63502191240f9830c7bd963c3f40188ecb9ae94411ed75e783f943412ad06a5d` |
| 사전 학습·연습 정답·이해도 기준·문법 도움말·용어집 | T1-draft / U1-draft / H1-draft | `26035851914d112ccf2a0a99cc30fad261601d8f2a941fcdf517c970bc7a6b4d` |

## 4. 연구 제한 (보고에 함께 적는다)

1. 불일치 중심 검토로는 AI들의 공통 오류를 다 찾아낼 수 없다.
2. Q5 단일 표본은 전체 GT의 정확도를 증명하지 않는다.
3. 해석을 공개한 뒤의 판단은 블라인드 판단이 아니다.
4. 그래프 선호는 주관적인 이해 용이성 평가다. 이해 성능이 객관적으로 나아졌다는 증거가 아니다.
5. 최초 판단과 최종 판단의 차이만으로 AI 의견이 판단을 개선했다고 결론 내리지 않는다.
6. 교육 자료와 한국어 용어 설명은 판단에 영향을 줄 수 있다. 그래서 모든 검토자에게 같은 버전을 주고, 해시로 고정한다.
